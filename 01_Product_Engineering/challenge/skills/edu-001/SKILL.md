# EDU-001: Upoznavanje zaposlenika s ključnim odrednicama kibernetičke sigurnosne politike

## When to use this
The consultant asked for an assessment of EDU-001 for one client.

## How to use it
Plan the searches, one query for each thing the control asks for, then run
`python run.py <client_id> "<query>"` for each query.

## What the control asks for
Edukacija mora biti potpuno implementirana i uz sve potrebne elemente provoditi se redovito za sve zaposlenike.

## References
- ISO/IEC 27001:2022 (A.5.4, A.6.3)
- ISO 22301:2019 (7.3)
- NIST SP 800-53 Rev. 5 (AT-2, AT-3, PM-13)
- NIST CSF v2.0 (PR.AT-1)
