# POL-001: Postojanje strateškog akta kibernetičke sigurnosne politike

## When to use this
The consultant asked for an assessment of POL-001 for one client.

## How to use it
Plan the searches, one query for each thing the control asks for, then run
`python run.py <client_id> "<query>"` for each query.

## What the control asks for
Strateški akt mora biti dokumentiran, mora sadržavati sve osnovne elemente, mora biti formalno usvojen od strane upravljačkog tijela i implementiran u poslovne procese subjekta te mora biti ažuriran po potrebi, kao i nakon provedbe procjene djelotvornosti mjera koja se mora provoditi najmanje jednom tijekom tekuće godine.

## References
- ISO/IEC 27001:2022 (5.2)
- ISO 22301:2019 (6.2)
- NIST SP 800-53 Rev. 5 (PM-1)
- NIST CSF v2.0 (Kategorija GV)
