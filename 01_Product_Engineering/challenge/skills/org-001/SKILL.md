# ORG-001: Raspodjela uloga, odgovornosti i obveza

## When to use this
The consultant asked for an assessment of ORG-001 for one client.

## How to use it
Plan the searches, one query for each thing the control asks for, then run
`python run.py <client_id> "<query>"` for each query.

## What the control asks for
Uloge i odgovornosti moraju biti jasno definirane, formalno dokumentirane, komunicirane relevantnim zaposlenicima koji su uključeni u provedbu sigurnosnih mjera i revidirane i ažurirane u skladu sbposlovnim potrebama i promjenama unutar subjekta.

## References
- ISO/IEC 27001:2022 (5.3, A.5.3, A.5.4)
- ISO 22301:2019 (5.3)
- ISO/IEC 27005:2022
- NIST SP 800-53 Rev. 5 (PM-1, PM-2, RA-1)
